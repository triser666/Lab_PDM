# Criterios de aceptación

Condiciones **específicas de una historia** que deben cumplirse para que el [[Product Owner]] la acepte.

Formato recomendado:
> **Dado** <contexto>, **cuando** <acción>, **entonces** <resultado observable>.

Con IA: cada criterio debe poder convertirse en un **test automático**; incluye al menos un caso de error. Diferencia con la [[Definición de Terminado (DoD)|Definición de Terminado]]: esta aplica a *todas* las historias.
